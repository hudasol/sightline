## Not verifiable by the reviewer
- **Same session:** whether the interval fps runs shared a session. They were made by one run script at commit 9a5c59b (commit message of 77823cd), but the JSON files record no session or start time, so this cannot be checked from the files.
- **Async commits:** the before/after async runs record no commit inside their JSON. The commits are in the commit messages (`results/README.md`).
- **MOT17 licence:** unverified (DATA_CARD).
- **Torch weight hashes:** the reviewer did not read the torch cache. MODEL_CARD lists them, and each matches the hash prefix in its torchvision file name.
- **Clean clone:** whether the GitHub repository is public, so a clean clone works, was not checked.
