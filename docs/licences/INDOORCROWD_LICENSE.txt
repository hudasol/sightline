IndoorCrowd licence (as recorded for Sightline, 2026-10-17)
===========================================================

Dataset: sebnae/IndoorCrowd on Hugging Face (gated), commit
87049647f27c4419dcba051474dcfc0fcecad8e0, last modified 2026-05-15.
Paper: Nae et al., "IndoorCrowd: A Multi-Scene Dataset for Human Detection,
Segmentation, and Tracking with an Automated Annotation Pipeline",
arXiv:2604.02032 (2026).

WHAT THE DATASET ITSELF SAYS
---------------------------
The dataset repository contains no licence file. Its metadata gives the
licence identifier:

    license: fair-noncommercial-research-license

and its dataset card ("Licensing Information") says, verbatim:

    The dataset is released under a license restricting its use strictly to
    non-commercial computer vision research. It prohibits surveillance and any
    re-identification of individuals.

The project page (sheepseb.github.io/IndoorCrowd) says the dataset is
"released for non-commercial computer vision research only" and links no
licence text.

HOW SIGHTLINE READS IT (the stricter reading)
---------------------------------------------
Both the card's sentence above and the full licence text below are treated as
binding, and where they differ the stricter one applies:

1. Non-commercial computer vision research only. IndoorCrowd is used in this
   repository only as offline evaluation data for a coursework project. Its
   frames, labels and any result computed on them are not used for, or carried
   into, any commercial product, service or decision.
2. No surveillance. Sightline is an advisory perception layer for a robot and
   is never connected to a camera network, a robot or a live feed. IndoorCrowd
   footage is only replayed offline to measure the pipeline. No IndoorCrowd
   result is used to monitor, count or follow real people.
3. No re-identification. Sightline uses anonymous, per-clip integer track ids
   from box geometry only. It has no appearance model, no face processing and
   no identity across clips. No IndoorCrowd identity, track id or crop is
   linked to a person, stored outside data/, or published.
4. No redistribution. IndoorCrowd frames and labels stay in data/ (git-ignored).
   Faces in the source are blurred by the dataset authors; Sightline still
   publishes no IndoorCrowd frame anywhere. Only aggregate metrics and the
   labels' file hashes are committed.
